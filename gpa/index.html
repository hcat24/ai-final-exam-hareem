Student GPA Calculator

Academic Program: Computer Engineering (International)
This application helps a student calculate GPA based on the transcript. The table is loaded automatically when the page opens. It contains the course name, credit, grade, and whether the course is passed. The last five rows are additional future courses from the program and are assumed to have grade A / 100, credit 6, and passed status Yes.

Information about GPA

Grade Point Average (GPA) is a weighted academic performance indicator. Each course has credits, and each final score is converted into a grade point. The GPA is calculated by multiplying the course credits by the grade points, adding these values together, and dividing by the total number of credits included in the calculation.

Formula: GPA = Σ(credit × grade point) / Σ(credit)

Grade point conversion used in this application:

  • A, 91–100 points = 4.0
  • B, 81–90 points = 3.2
  • C, 71–80 points = 2.4
  • D, 61–70 points = 1.6
  • E, 51–60 points = 0.8
  • FX, 41–50 points = 0
  • F, 0–40 points = 0

A course is considered passed if the final score is at least 51. Failed courses receive 0 grade points. Courses that are still in progress are shown in the table, but they are not included in the normal GPA calculation until a final score is assumed or available.

The second button assumes that the final score for Introduction to Artificial Intelligence equals the current accumulated points plus 30 final exam points. For example, with 65 current points, the assumed final score is 65 + 30 = 95.

This web application is made as exactly one HTML file. CSS and JavaScript are embedded inside this file. No external libraries, frameworks, CDNs, or additional files are used.
